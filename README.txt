ÁLBUM DIGITAL DE PETS — VERSÃO PREMIUM

ESTRUTURA:
index.html
fotos/
musica/

FOTOS:
Coloque até 40 fotos na pasta fotos.
Numere apenas os arquivos:
1.jpg
2.png
3.webp
4.jpeg
...
40.jpg

O sistema reconhece automaticamente jpg, jpeg, png, webp, gif e avif.

MÚSICA:
Coloque uma música em musica/ usando, preferencialmente, musica.mp3.
Também são aceitos ogg, wav, m4a e aac.

GITHUB PAGES:
Envie os arquivos para um repositório, depois ative Settings > Pages > Deploy from branch > main > /root.

PERSONALIZAÇÃO:
O nome "Meu Pet" e os textos podem ser alterados diretamente no index.html.
